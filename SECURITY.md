# Security Policy

## Supported versions

Security fixes go into the latest release only. If you run an older version, upgrade before reporting.

## Reporting a vulnerability

**Please don't open a public issue for a security vulnerability.**

Report it privately through [GitHub private vulnerability reporting](https://github.com/redemptia/redemptia/security/advisories/new), with:

- a description of the issue and its impact;
- steps to reproduce (a proof of concept helps);
- the version or commit you tested;
- your name or handle, if you'd like credit in the disclosure.

Please allow reasonable time to investigate and release a fix before disclosing publicly.

## Scope

This repository's code. Third-party services a deployment is configured to use (scraping providers, model APIs, Stripe, Resend) are out of scope; report issues with those to their vendors.
