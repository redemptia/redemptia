## Prerequisites

- **Docker** — Docker Engine 24+ with Docker Compose v2
- **Node.js** — 18.x or later (for the CLI)
- At least one AI provider API key (OpenAI, Anthropic, or OpenRouter)
- **(Recommended)** A scraping provider to track the real ChatGPT and Google AI Mode experiences — see [Providers](/docs/user-guide/providers)

## Install the CLI

```bash
npm install -g @redemptia/cli
```

## Initialize Your Instance

Run the interactive setup wizard:

```bash
redemptia init
```

The wizard walks you through:

1. **Config directory** — Where to store your `redemptia.yaml` and `.env` files (default: `./redemptia`)
2. **PostgreSQL** — Run Postgres in Docker (recommended) or provide an existing `DATABASE_URL`
3. **AI Providers** — Configure scrapers ([Cloro](https://cloro.dev/), [BrightData](https://brightdata.com/), [Oxylabs](https://oxylabs.io/), [SearchApi](https://www.searchapi.io/), [Olostep](https://olostep.com/), [DataForSEO](https://dataforseo.com/)) and/or direct model APIs (OpenAI, Anthropic, Mistral, OpenRouter); see [Providers](/docs/user-guide/providers) for details
4. **Access** — Use Redemptia on this machine (localhost), or from a domain behind a reverse proxy (see [Serving Redemptia from a Domain](/docs/developer-guide/configuration#serving-redemptia-from-a-domain))
5. **Start** — Optionally start the stack immediately

Once complete, Redemptia generates two files in your config directory:

| File | Purpose |
|------|---------|
| `redemptia.yaml` | Docker Compose configuration for all services |
| `.env` | Environment variables, secrets, and API keys |

## Start Redemptia

If you didn't start during init, bring everything up with:

```bash
redemptia compose up -d
```

This pulls the Docker images and starts all services. Once they report healthy, open **http://localhost:1515** in your browser.

## System Architecture

| Service | Role |
|---------|------|
| **Web** | Dashboard UI and REST API |
| **Worker** | Background scheduler that drives prompt runs |
| **Postgres** | Shared database and job queue |
| **LLM APIs** | Direct API calls (OpenAI, Anthropic, OpenRouter) |
| **LLM Scraper** | Scrapers for ChatGPT, Google AI Mode, and other live AI surfaces ([Cloro](https://cloro.dev/), [BrightData](https://brightdata.com/), [Oxylabs](https://oxylabs.io/), [SearchApi](https://www.searchapi.io/), [Olostep](https://olostep.com/), [DataForSEO](https://dataforseo.com/)) |
| **Redemptia CLI** | Generates `redemptia.yaml` + `.env` and runs `docker compose` |

## CLI Commands Reference

Once Redemptia is running, these commands help you manage it:

```bash
# View live logs
redemptia compose logs -f

# View logs for a specific service
redemptia compose logs -f web

# Check service status
redemptia compose ps

# Stop all services
redemptia compose down
```
